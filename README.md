# Лабораторная работа № 3 — вариант 6 (Трек A)

**Дисциплина:** «Эволюционное программирование и генетические алгоритмы» (НИЯУ МИФИ)  
**Тема:** Эволюционный синтез и многокритериальная оптимизация: алгоритм NSGA-II  
**Вариант:** 6 — «Формирование меню на неделю»  
**Критерии оптимизации:**
1. $f_1 \to \min$: Стоимость недельного меню (руб.);
2. $f_2 \to \min$: Среднесуточное относительное отклонение от целевых нутриентов: калорий, белков, жиров, углеводов (%);
3. $f_3 \to \min$: Монотонность рациона (обратная величина к разнообразию блюд, кухонь и источников белка, %).

Проект выполнен на чистом Python 3 без использования сторонних фреймворков эволюционной оптимизации (pymoo, DEAP и др.). Визуализация и графики строятся в векторном формате SVG и интерактивном 3D HTML исключительно средствами стандартной библиотеки.

## Инструкция по запуску

### 1. Быстрый запуск всей серии экспериментов

Для воспроизведения серии из 20 запусков NSGA-II, генерации отчетов и построения всех диаграмм выполните:

```bash
python3 generate_data.py
python3 run_experiments.py
```

Команда выполнит:
- 20 прогонов NSGA-II со случайными зернами от `3000` до `3019`;
- Прогон метода взвешенной суммы по сетке весов;
- Прогон случайного поиска при сопоставимом бюджете (15 000 оценок);
- Расчет метрик Hypervolume, Spacing, времени и характеристик фронта;
- Экспорт всех CSV-таблиц, SVG-графиков и HTML-визуализатора в папку `outputs/`.

### 2. Единичный запуск NSGA-II с заданным seed

Для запуска одиночной оптимизации с выводом промежуточных поколений:

```bash
python3 nsga2_menu.py --seed 3000 --pop 100 --gen 150 --verbose
```

Параметры командной строки:
- `--seed <int>`: начальное зерно датчика псевдослучайных чисел (по умолчанию `3000`);
- `--pop <int>`: размер популяции (по умолчанию `100`);
- `--gen <int>`: число поколений (по умолчанию `150`);
- `--verbose`: вывод прогресса каждые 25 поколений.

### 3. Просмотр интерактивного 3D фронта Парето

Файл `outputs/pareto_3d_viewer.html` можно открыть в любом современном веб-браузере:
```bash
open outputs/pareto_3d_viewer.html
```
Интерфейс позволяет вращать трехмерный фронт левой кнопкой мыши, масштабировать колесиком, переключать видимость алгоритмов (NSGA-II, WSGA, Random Search) и просматривать состав любого меню при наведении курсора.

## Ключевые результаты

1. **Реализация NSGA-II с нуля**:
   - Быстрая недоминируемая сортировка по Дебу $\mathcal{O}(M N^2)$;
   - Назначение расстояния до скопления (crowding distance) $\mathcal{O}(M N \log N)$;
   - Crowded-comparison оператор $(\prec_n)$ в турнирной селекции;
   - Элитарное формирование популяции $P_{t+1}$ из объединенного пула $R_t = P_t \cup Q_t$ ($2N$ особей);
   - Внешний архив Парето-оптимальных решений.
2. **Сравнение со взвешенной суммой критериев (WSGA)**:
   - NSGA-II находит плотный и равномерный фронт из 100 решений за один запуск ($HV = 0.485$, $Spacing = 16.20$);
   - WSGA требует множества раздельных запусков под разные векторы весов, находит лишь 14 крайних решений ($HV = 0.463$, $Spacing = 118.86$) и фундаментально не способна находить вогнутые участки фронта.
3. **Выделены 4 репрезентативных меню**:
   - «Бюджетное»: 3 485 руб./нед. (экономное, базовый баланс нутриентов);
   - «Сбалансированное»: ошибка БЖУ всего 14.6% (оптимальное попадание в нормы 2200 ккал / 95 г Б / 75 г Ж / 280 г У);
   - «Разнообразное (Гурман)»: 21 уникальное блюдо за неделю (монотонность 0.0%, максимальное разнообразие кухонь и источников белка);
   - «Компромиссное (Knee Point)»: 4 820 руб./нед., ошибка нутриентов 18.2%, 18 уникальных блюд — наилучший баланс всех трех критериев.
